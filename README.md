# Answerworthy — personal source pointer

The canonical Answerworthy Standard lives in [answerworthy/answerworthy.md](https://github.com/answerworthy/answerworthy.md). This personal repository preserves earlier source and points to the canonical project; it does not maintain or release a separate specification.

Resolve and read the [living canonical Standard](https://raw.githubusercontent.com/answerworthy/answerworthy.md/main/README.md) before applying or continuing a business file, including when an older link resolves to this README. The canonical source owns the current version declaration and normative meaning.

```text
Get started with https://answerworthy.md
```

Use the Standard independently with a capable agent or practitioner. A paid account or private repository is not required.
